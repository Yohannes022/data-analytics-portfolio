## Getting started

1. Clone this repository.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`.
4. Copy `templates/project-template/` into `projects/` and rename it.
5. Replace every placeholder in the project README before publishing.

## Project quality standards

- State a specific question and explain why it matters.
- Cite the dataset source, license, date accessed, and limitations.
- Keep raw data unchanged; document cleaning and transformations.
- Do not commit secrets, personal data, or large files without a clear reason.
- Make analysis reproducible and validate important results.
- Separate exploration from reusable production code.
- Include screenshots only when they add explanatory value.
- Never invent findings, metrics, or business impact.
