# Contributing to this portfolio

This is an individual learning portfolio. Use the following workflow for consistent, reviewable changes.

## Branches

- `main`: stable, documented work.
- `feature/<short-description>`: a focused change or project addition.

## Commit messages

Use clear, action-oriented messages:

- `feat: add monthly price trend analysis`
- `fix: handle missing date values`
- `docs: explain dataset limitations`
- `test: add validation for aggregation results`
- `refactor: move cleaning logic into reusable functions`

Do not create artificial commits to manipulate the contribution graph. Commit when a meaningful unit of work is complete.

## Before pushing

- Run the project code from a clean environment.
- Check that paths are relative and secrets are excluded.
- Confirm that dataset licensing permits redistribution.
- Update the relevant README.
